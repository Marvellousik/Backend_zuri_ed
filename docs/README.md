# Zuri Documentation Directory

Welcome to the Zuri technical documentation hub. All architectural specifications, API contracts, integration guides, and deployment runbooks are organized into the directories below.

---

## Directory Overview

### 1. API & Service Architecture (`/docs/api`)
- [API Documentation](file:///workspaces/Backend_lexi/docs/api/API_DOCUMENTATION.md) — Comprehensive reference for all API Gateway endpoints, request/response formats, authentication headers, error codes, and rate limits.
- [Service Documentation](file:///workspaces/Backend_lexi/docs/api/SERVICE_DOCUMENTATION.md) — Detailed specifications for each microservice (Go and Python), internal ports, communication protocols, and data stores.

### 2. Client Integration Guides (`/docs/integration`)
- [Frontend Integration Guide](file:///workspaces/Backend_lexi/docs/integration/FRONTEND_INTEGRATION_GUIDE.md) — Integration guide for the Next.js web client with authentication, course management, quizzes, and AI tools.
- [Staging Frontend Guide](file:///workspaces/Backend_lexi/docs/integration/Zuri_Frontend_Integration.md) — Environment configuration and staging backend connectivity guide.
- [Mobile Integration Guide](file:///workspaces/Backend_lexi/docs/integration/MOBILE_INTEGRATION_GUIDE.md) — React Native mobile app architecture, state management, and API gateway integration.
- [Mobile Screen Developer Guide](file:///workspaces/Backend_lexi/docs/integration/MOBILE_SCREEN_DEVELOPER_GUIDE.md) — Cheat sheet for mobile screen developers with required headers and response structures.
- [Integration Plan](file:///workspaces/Backend_lexi/docs/integration/INTEGRATION_PLAN.md) — Phased system integration roadmap and verification milestones.

### 3. Deployment & Infrastructure (`/docs/deployment`)
- [Database Setup Guide](file:///workspaces/Backend_lexi/docs/deployment/DATABASE_SETUP_GUIDE.md) — PostgreSQL setup, pgvector configuration, extensions, connection pooling, and migration procedures.
- [Render Deployment Guide](file:///workspaces/Backend_lexi/docs/deployment/RENDER_DEPLOY_GUIDE.md) — Blueprint deployment instructions for Render containerized services and environment variables.

### 4. Demo & Walkthrough (`/docs/demo`)
- [Demo Script](file:///workspaces/Backend_lexi/docs/demo/DEMO_SCRIPT.md) — End-to-end presentation and testing flow covering auth, content generation, and AI features.
